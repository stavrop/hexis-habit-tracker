# Hexis Habit Tracker

A calm, private habit tracker for iOS & watchOS.

This public repository is the home of Hexis's **[Privacy Policy](https://stavrop.github.io/hexis-habit-tracker/)**
and its **issue tracker** — the app's *Report a Bug* and *Suggest a Feature*
buttons open issues here.

- 🐛 [Report a bug](https://github.com/stavrop/hexis-habit-tracker/issues/new?labels=bug&template=bug_report.md)
- 💡 [Suggest a feature](https://github.com/stavrop/hexis-habit-tracker/issues/new?labels=enhancement&template=feature_request.md)
- 🔒 [Privacy policy](https://stavrop.github.io/hexis-habit-tracker/)

The app source lives in a separate repository.
